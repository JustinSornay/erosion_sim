# Slope experiments

Hypothesis: erosion capacity should depend more directly on slope aligned with
flow. `directional-slope-comparison.js` evaluates the fully directional model;
the hybrid scripts sweep blended factors and measure their throughput.

Result: directional slope improves early source distribution but weakens global
erosion. No hybrid factor meets long-run hydraulic and morphological criteria.
Both approaches are rejected; production retains its historical behavior.
