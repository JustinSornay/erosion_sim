# Test Suite

## Philosophy

This suite separates regression tests, diagnostics, experimental physics variants,
performance benchmarks, fixtures, and generated artifacts. Historical research
scripts remain reproducible without being mistaken for production guarantees.

## Production invariant

Scripts in `diagnostics/` and `experiments/` never modify
`js/simulation/simulation.js` to run. Experimental variants are injected only
into their isolated benchmark source environment.

## Directory map

- `regression/` — deterministic production-behavior protections.
- `diagnostics/` — observations and analyses of existing production behavior.
- `experiments/` — benchmark-only candidate physics variants, grouped by topic.
- `benchmarks/` — generic performance measurements.
- `fixtures/` — versioned deterministic binary reference buffers.
- `generated/` — versioned research outputs: regenerable PPM captures and logs.

Generated artifacts are intentionally versioned as historical evidence. They can
be regenerated by their owning experiment and are not production inputs.

## Running tests

```sh
node tests/regression/physics-determinism.js
node tests/regression/source-injection.js
node tests/regression/source-routing-stability.js
node tests/regression/physics-regression.js 1000
node tests/diagnostics/terrain-slope-evolution.js
node tests/benchmarks/physics-benchmark.js
```

Experiments are explicit research runs; see each experiment README before
interpreting results. `--write-captures` regenerates morphodynamic PPM artifacts.

## Potential future test utilities

Candidates remain intentionally local: `traceReferencePath`, `section`,
`percentile`, `slopeStats`, deterministic simulation wrappers, and source-string
builders. Extracting them now could subtly alter historical benchmark behavior
and reduce reproducibility.
