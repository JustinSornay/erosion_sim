# Version 2.1.1 — Retour des générations originelles

- Réintégration de **Terrain naturel** dans la rotation de découverte, aux côtés
  des huit familles déjà présentes. Les mêmes graines retrouvent exactement
  les terrains fractals des premières versions.
- Une génération classique n'est pas présentée comme un zoom : le sélecteur
  indique « Génération classique » dans le même style discret.
- Les sessions et historiques 2.1.0 restent compatibles. Au premier chargement
  après mise à jour, si une rotation est en cours, ce type historique est
  proposé dès la prochaine génération, sans l'ajouter une deuxième fois
  aux rechargements suivants.
- Aucun changement d'interface, de solveur physique, de caméra, de rendu ou de
  sauvegardes. Les cuvettes aléatoires du terrain naturel sont intentionnelles.
